# Azure Cloud Utility Platform

A web-based utility application deployed on production-style Microsoft Azure infrastructure.

## Project Status

🚧 Under Development

## Overview

The Azure Cloud Utility Platform is a web-based utility application designed to demonstrate practical cloud engineering skills using Microsoft Azure.

The application will provide simple calculation, conversion, and networking utilities while the underlying Azure platform demonstrates real-world cloud infrastructure and operations.

## Project Focus

This project demonstrates:

- Microsoft Azure infrastructure
- Cloud networking
- Linux administration
- Compute and storage
- Identity and access management
- Security fundamentals
- Monitoring and observability
- Infrastructure as Code
- Troubleshooting and recovery

## Planned Application Features

- Calculator
- Percentage and discount calculator
- Data-size converter
- CIDR and subnet calculator

## Technology Stack

- Microsoft Azure
- Terraform
- Python
- Linux
- Git
- GitHub
- Azure CLI
